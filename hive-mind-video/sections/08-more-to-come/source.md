- Default answer is No — do nothing, you'll get overrun

## The Yellow Brick Road
- Spending tokens — the golden shimmering trail
- New bottlenecks emerge when coding is no longer the bottleneck
- Need to start learning bespoke organizational lessons early
- Token spend reveals how much practice people are getting
